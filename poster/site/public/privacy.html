Privacy Policy

Tired Linguist Poster · Last updated 26 November 2026

What this app is

Tired Linguist Poster is a private tool that lets its owner schedule and publish videos to the owner's own social media accounts. It has no public users.

Data we access

When the owner connects a Google account, the app requests permission to upload videos to YouTube and to read basic channel information (such as the channel name). If an Instagram account is connected, the app requests permission to publish content to that account.

How the data is used

Access is used only to upload and publish the owner's own videos at the times the owner chooses, and to show which channel a post is going to. The app does not read, collect or analyse other users' data, comments or viewing activity.

Storage and security

Sign-in tokens, scheduled post details and video files are stored only as long as needed to publish them, in secured storage accessible only to the owner. Data is not sold, shared with third parties or used for advertising.

YouTube API Services

This app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See also the Google Privacy Policy. You can revoke the app's access at any time from your Google security settings.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data
